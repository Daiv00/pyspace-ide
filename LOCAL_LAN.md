# PySpace: локальное хранилище по Wi‑Fi

Это отдельный режим от Render. В локальном режиме PySpace запускается на компьютере-хосте и слушает `0.0.0.0:8080`.

## Windows

Запустите `run_windows.bat`. Если Windows Firewall спросит про Python, разрешите доступ к частным сетям.

## Linux/macOS

Запустите `./run_linux.sh`.

После входа нажмите **Обмен** → создайте локальную ссылку. PySpace покажет адрес вида:

`http://192.168.1.20:8080/share/...`

и QR-код. Телефон/другой компьютер должен быть в той же Wi‑Fi сети.

Получатель может открыть ссылку без аккаунта, отправить несколько файлов или текст. Файлы сохраняются в папке `local_hub/` на компьютере-хосте и не удаляются при отключении телефона.

Если используется другой порт, задайте `PORT`. Если PySpace неправильно определяет Wi‑Fi IP, можно задать `PYSPACE_LAN_HOST=192.168.1.20` или `PYSPACE_LAN_URL=http://192.168.1.20:8080`.

## Render

Render — это облачный сервер. Он не может превратиться в ваш домашний Wi‑Fi-хост. На Render общая ссылка будет работать через интернет, а постоянное хранилище требует отдельного persistent disk/object storage.
